# Vault Heist

A C++ data structures visualization game.

## Project Structure

- backend: Data structures and algorithms
- middleware: Game logic and backend-frontend communication
- frontend: SFML graphics and user interface
- assets: Fonts, images and sounds
- data: Level configurations and save files
- tests: Backend and middleware tests
- docs: Project documentation

## Technologies

- C++
- SFML
- VS Code
- Git and GitHub
